**The word: Ghosted**

The Wi-Fi didn't drop — it *ghosted* you. It vanishes mid-call, mid-download,
mid-sentence, then drifts back hours later like nothing happened. That is the
single most recognisable thing home Wi-Fi does, told in one plain word anyone
gets instantly, with no pun to explain and no context needed. And as the
sponsor's network name it keeps the joke running: every phone in range would
be trying to connect to "Ghosted".

`main.py` writes the word to `/output/entry.txt` (override the path with the
`ENTRY_OUTPUT` env var for local testing).
